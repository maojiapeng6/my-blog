## 项目概述

「扇韵连连趣」是一个用 Python + pygame 写的消消乐小游戏，窗口 850×600。它是省级创新创业项目「金陵流华·西游扇影」的交互交付物——把非遗金陵折扇的四种形态（竹板扇、掌扇、团扇、绫绢扇）做成游戏里的彩色棋子，玩家在一个能直接双击运行的小程序里把折扇文化"玩一遍"。

## 技术要点

| 模块 | 职责 |
| --- | --- |
| `main.py` | 主循环、事件分发，不写游戏逻辑 |
| `ManagerTree` | 主菜单：扇面选关树、能量与金币 |
| `Manager` | 关卡：棋盘、消除、下落、结算 |
| `SoundPlay` | 主界面 BGM 与关卡 BGM 自动切换 |

四个核心算法：

- **相邻消除**：先标记后清空，避免遍历中删元素导致索引错位
- **交换判定**：交换后无消除则立即回退，保证原子性
- **下落补位**：按列独立处理，补位后再次扫描以支持连锁
- **死局检测 `death_map()`**：无可行解时整体重排，避免玩家点不动

## 我做了什么

- **状态驱动重构**：把"主菜单/关卡"的判断从主循环里拆出来，改由 `level` 状态驱动，改一个关卡规则不必通读主循环
- **死局检测与重排**：补上最容易被漏掉的 `death_map()`，彻底消除"棋盘无解卡死"的体验缺口
- **消除与补位原子化**：消除-下落-补位-再扫描形成闭环，支持连锁反应
- **音效状态机**：主界面与关卡的 BGM 切换做成独立逻辑，退出关卡时能正确切回
- **素材规格统一**：背景 850×600、格子砖 218×218、棋子 40×40，按此比例布局避免拉伸变形

## 收获

第一次完整走通"想法 → 能跑 → 能演示 → 能讲清楚"这条链。真正的难点不在匹配算法，而在边界情况：点不动了怎么办、交换不成功怎么办、棋盘全死了怎么办。

> 从"代码能跑"到"别人玩着不卡"，中间全是边界情况。
